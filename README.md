# 🎈 Balloon Blast Game

A fun mini-game prototype where users can pump and inflate balloons, watch them float, and pop them by tapping — built using **HTML, CSS, and JavaScript**.

## 🎮 Game Description

- **Pump the Balloon**: Click the air pump to inflate a balloon.
- **Balloon Floats**: Once filled, the balloon floats randomly around the screen.
- **Burst the Balloon**: Tap on the balloon to pop it with a blast animation.

This game is inspired by a demo shared for an internship assignment by IDZ Digital.

## 🧰 Tech Stack

- **HTML**
- **CSS**
- **JavaScript**
- Designed for integration into **React + Vite** if needed.
